## A Progression Through the Set

An iron set is intended to provide several useful distances. Lower-numbered irons generally have less loft and longer shafts, while higher-numbered irons have more loft and shorter shafts. PING's i230 specification table shows these changes across one particular model family. Specifications are useful because the number on an iron is not a universal loft standard. [1]

Golfers often describe irons as long, mid, or short, although the exact boundaries can vary. These groups are a convenient way to discuss the set rather than a strict classification rule.

## Think in Distances, Not Just Numbers

Suppose a golfer's 5-iron and 6-iron finish at nearly the same carry distance. Owning both numbers does not necessarily create two distinct shot options. That golfer could investigate contact, launch, or a different arrangement at the longer end of the bag. This is an example of set planning, not a claim that everyone should replace a particular iron.

### Connect the Ends of the Set

The longest iron should make sense beside the fairway woods or other longer clubs. At the opposite end, the shortest irons should connect logically to the wedges.

A simple distance notebook can record the club, typical carry, and common miss. Over several practice sessions, that information is more useful than remembering one unusually long shot. Modern specification choices make customization possible, but a useful progression still depends on the player's repeatable results.
